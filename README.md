



# Selko

## Disclaimer ##

not affiliated with Kela, Migri or Vero, and not legal advice; always check the official source.
## Problem ##


The newcomers struggle to find and understand Finnish public service information

## Overview ##

This project will gather documents and information available to newcomers from sources like Kela, Migri, and Vero, and provide a RAG solution where they can ask questions in english and get an answer with citations to the official Finnish pages.

## Project status ##

Early development - Phase 0: project setup

## Planned tech stack ##

Python, uv, embeddings, a vector database, an LLM, FastAPI, Docker.
